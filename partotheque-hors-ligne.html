Configuration requise

Cette page lit un catalogue pré-généré, avec possibilité de synchroniser des PDF pour un usage hors-ligne.

  1. Exécutez le script generer-catalogue.gs depuis script.google.com : il crée un fichier catalogue.json dans le dossier Drive.
  2. Récupérez l'ID de ce fichier dans le journal d'exécution du script.
  3. Collez cet ID dans CONFIG.CATALOG_FILE_ID tout en haut du code source de cette page.
  4. Déposez cette page avec manifest.json, sw.js et les icônes dans le même dossier sur votre hébergement (GitHub Pages) pour profiter du mode hors-ligne complet et de l'installation sur l'écran d'accueil.
  5. Enregistrez et rechargez la page.
