Configuration requise

Cette page lit un catalogue pré-généré (rapide et fiable) plutôt que de parcourir Drive en direct.

  1. Exécutez une fois le script generer-catalogue.gs (voir ses propres instructions) depuis script.google.com : il crée un fichier catalogue.json dans le dossier Drive.
  2. Dans le journal d'exécution du script, récupérez l'ID du fichier catalogue.json généré.
  3. Collez cet ID dans la constante CONFIG.CATALOG_FILE_ID tout en haut du code source de cette page.
  4. Si ce n'est pas déjà fait, renseignez aussi CONFIG.API_KEY (clé API Google Cloud avec l'API Drive activée — voir la documentation Google Cloud Console si besoin).
  5. Enregistrez et rechargez la page.
